**Category:** AI Agent / Full Stack

### B) Revela (Ongoing)
**Category:** Tangible Interfaces / Interaction Design  
**Role:** Circuit Design, Hardware Prototyping, Physical Computing  

**Problem**
- Children (ages 4-7) need help finding objects, but screen-based solutions add distraction.

**What was built**
- Screen-free embedded interaction system using a wand and distributed beacon nodes.
- Continuous proximity guidance via color-mapped LED feedback.

**Technical implementation**
- Explorer wand with ESP32-S3 XIAO + NeoPixel strip + Li-Po power/charging system.
- Beacon nodes based on ESP32-C2 modules.
- Continuous signal-response loop with sub-second perceived feedback.
- Iterative testing for power stability, heat, reliability, and form ergonomics.

**Resume-grade outcomes**
- Developed a complete hardware-software interaction loop.
- Solved reliability issues through iterative debugging and integration testing.
- Demonstrated physical computing and human-centered interaction design together.
